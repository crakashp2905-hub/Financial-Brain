# PE-0205 independent review evidence

Added a pull request template requiring the author to state financial behavior impact, identify a reviewer other than the author for return/order/risk/accounting changes, record failure scenarios and test results, attach evidence paths and hashes, list limitations, and describe rollback and persistence compatibility.

This is a process aid; it does not itself prove a qualifying independent review or enforce GitHub branch protection. Repository protection settings and an actual reviewer decision remain external.
