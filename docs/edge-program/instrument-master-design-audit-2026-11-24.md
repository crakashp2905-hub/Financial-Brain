# Source-aware instrument master design audit — 2026-11-24

**Checklist:** `PA-02-04` — `PARTIAL`.

The repository now defines `fb.instrument_master.v1` and a typed, hash-bound `InstrumentMaster`. Records retain provider/source ID and token, canonical identity, exchange/segment, symbol, ISIN, effective dates, futures/options underlying and expiry, exact option strike/right, lot/tick rules, source publication time, local receipt time and source payload hash. Effective-dated adjustments carry their own source and timestamps. Reused source tokens cannot have overlapping identities. Option resolution requires an exact listed source-backed contract and returns `NO_OPTION_TRADE` when that contract is absent; the resolver never generates a strike. Index candidate reconciliation also returns `NO_OPTION_TRADE` unless an unexpired source-listed option contract exists for the exact canonical underlying. The existing `InstrumentRuleBook` remains the separate dated order-validation layer.

The v1 JSON schema defines the persisted document shape, and the content digest binds the normalized records and adjustment entries. Verification: `tests/test_forward_edge_instrument_master.py` (12 passed), including schema validation, effective ISIN/token history, overlap rejection, provenance checks, adjustment dates, deterministic round-trip, exact option lookup and index-candidate `NO_OPTION_TRADE`. Scoped Ruff and mypy passed; source, capability ownership, entry-point and forward-engine dependency inventories were refreshed.

This is the validated contract and resolver, not a populated exchange instrument master. No authorized Kite/NSE/BSE snapshot archive, historical contract ingestion adapter, or verified real source-published/received timestamps are present. The optionability reconciliation is therefore only as complete as the supplied master snapshot and does not prove all index constituents or live contracts are covered. Provider rights for retention and replay remain unknown, so PA-02-04 and PA-02-05 stay partial until licensed source records can be acquired and reconciled.
