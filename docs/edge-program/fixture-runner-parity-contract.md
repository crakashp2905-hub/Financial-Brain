# Fixture replay through the forward session runner

The deterministic fixture pack is converted into normalized `QUOTE` and `TICK`
events with exchange, receive and availability clocks. Fixture decisions, risk,
preflight and execution outcomes then pass through `ForwardSessionRunner`, its
durable event journal and transactional outbox. The fixture executor uses the
same `forward_edge.execution` functions as the historical report pipeline.

The compatibility report keeps its documented fields and canonical signatures.
Its accounting projection now consumes the receipt generated by the runner;
it does not independently calculate the execution outcome. Existing golden
signatures detect changes to report behavior.

The lost-ack fixture leaves an `OUTBOX_UNKNOWN` and cannot be closed or resent.
Cash/broker modes are refused. These are synthetic engineering fixtures and do
not establish live data, execution quality, profitability or paper-session
evidence.
