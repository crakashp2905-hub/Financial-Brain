# Paper-decision evidence contract (W2)

`fb.decision.v1` is a canonical JSON snapshot of a **paper-research** decision. It binds the recorded champion picks to strategy/model/data/universe/calendar/cost/risk digests, capital, forecast quantiles, selections, exclusions, source publication/receipt times, and an earliest entry and planned exit. Decimal quantities are strings; UTC instants and member ordering are normalized before SHA-256 hashing. Unknown fields, future-received sources, duplicate lineages, invalid weights and malformed forecasts are rejected.

The local workflow is `prospective.record` → `prospective.attach_manifest` → `prospective.attach_anchor`. The manifest must match the immutable pick digest and local recording timestamp. The receipt must refer to the **entire manifest digest**, be recorded before the earliest next-calendar-day 09:15 IST entry, and be reverified on each read. Legacy pick-only receipts do not qualify. `verified_days` returns an empty set by default: a local timestamp or hash is not independent evidence.

An owner must still choose an independent timestamp/signature provider, pin its verification key and rotation policy, and implement a verifier that authenticates provider, day, full manifest digest, receipt and timestamp. No provider, trusted key, external receipt, exchange-calendar proof, or actual prospective cohort is configured by this change. Caller-supplied source and configuration hashes also need reproducible artifacts and custody checks. A test callback that returns true is **not** production attestation. The existing 2026Q4 trial budget and protected holdout remain unchanged; this contract does not authorize live orders or establish a profitable edge.

Operational acceptance requires: independently retrievable signed receipts; clock and calendar checks; replay/tamper/key-rotation drills; immutable artifact retention; matching prospective entry and outcome records; and an owner-reviewed champion/challenger decision. Until then, use local records for diagnostics only and keep promotion fail-closed.
