# OntoBricks

**Ontology / knowledge-graph runtime**

Turns Databricks/Unity Catalog data into a living knowledge graph: OWL/RDFS, R2RML,
materialised triples, reasoning, SHACL, GraphQL, **MCP access for agents**.

Caveat: presumes Databricks. Our [[Knowledge Graph]] need not. Take the ontology
modelling approach; evaluate the runtime separately.
