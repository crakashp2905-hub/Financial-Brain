# Agent Memory

**Coding-agent memory — not financial memory**

Confidence, lifecycle, knowledge graphs, hybrid search, MCP. ~95.2% recall on
LongMemEval-S with ~92% fewer tokens.

**Coding-agent memory != financial memory.** We need company, strategy, research,
decision, portfolio, outcome, regime and preference memory — and
[[Decision Database]] is not a vector store. Take the lifecycle/confidence ideas only.
