# Fincept Terminal

**Terminal architecture and MCP tool-surface reference**

Native C++/Qt with embedded Python: 54 screens, ~50 services, 40+ MCP tools, 16
equity/F&O brokers; bounded contexts for Markets, News, Economics, Trading, Portfolio,
Derivatives, Predictions, Agents, AI Chat; workflow/node editor, paper trading.

Best available reference for terminal architecture and the MCP tool surface.

> [!danger] Do not fork commercially
> Modified distribution or SaaS triggers AGPL source release; Enterprise is proprietary.

Worth stealing conceptually: the **visual workflow builder**, which makes the system
useful with the LLM switched off.
