# OpenViking

**Context OS — hierarchical memory behind a replaceable interface**

Context database where memories, resources and skills live in one virtual filesystem
(`viking://`), with **L0/L1/L2 hierarchical context layers**, dual-layer storage (AGFS +
vector index, single source of truth), and automatic 6-category memory extraction.

Hierarchical retrieval is exactly right for research:
L0 "Momentum research" -> L1 {academic evidence, Indian evidence, factor construction,
regime effects, transaction costs} -> L2 {papers, equations, datasets, backtests}.
Beats loading 10,000 documents.

AGPL -> replaceable interface only. See [[D4 OpenViking replace or add]].
