# The closed loop

The project does not become a Financial Brain by adding agents, repositories or model
providers. It becomes one by operating a reliable, measurable, governed loop:

```
Observe -> Verify -> Model the market -> Form a thesis -> Size risk
   -> Decide -> Record -> Observe outcome -> Diagnose -> Improve
```

The durable IP is the loop's memory:

```
Evidence -> Thesis -> Decision -> Outcome -> Postmortem -> Calibrated future judgement
```

Implemented by [[C09 Evidence ledger]], [[C17 Decision record and lifecycle]] and
[[C25 Outcome attribution and calibration]].
