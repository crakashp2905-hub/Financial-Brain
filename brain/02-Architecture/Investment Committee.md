# Investment Committee

Six agents plus orchestrator — not twenty.

```
Fundamental · Technical · Sentiment analysts
   -> Macro/Regime Analyst -> Event Analyst
   -> BULL vs BEAR debate -> Thesis Engine
   -> Trader -> Risk Manager -> Portfolio Manager
   -> Paper trade -> Outcome -> Adapt
```

**Measure disagreement, don't eliminate it** — Fundamental↔Technical HIGH,
Social↔Fundamental LOW, Bull↔Bear HIGH is itself information.

Per-agent track records drive dynamic weighting: strong trend -> technical ↑; earnings
season -> fundamental ↑; macro shock -> macro + risk ↑.
