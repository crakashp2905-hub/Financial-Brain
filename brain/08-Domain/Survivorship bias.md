# Survivorship bias

NSE/BSE bhavcopy archives do contain delisted names historically, but the point-in-time
universe must be reconstructed: delistings, suspensions, symbol changes, mergers, T2T
moves, ASM/GSM inclusion. There is **no clean published "NIFTY 500 membership as of
date X"** series.

Without it, momentum and quality backtests overstate returns materially — the failures
are exactly the names missing from a current-universe dataset.
