# D1 Personal tool or product

> [!question] Changes AGPL exposure, data budget, and whether SEBI RA/RIA registration is on the critical path.

**Decide this first — it gates everything else.**

| If personal | If product |
|---|---|
| AGPL resources usable | [[OpenBB]], [[OpenViking]], [[Fincept Terminal]] all become problems |
| Kite personal feed fine | Exchange data-redistribution agreement needed |
| No registration | SEBI RA/RIA registration on the critical path |
| Screener/Moneycontrol pragmatic | Licensed feeds required |

Recommendation: **build personal first**, keep every AGPL dependency behind an interface
so the door stays open.
