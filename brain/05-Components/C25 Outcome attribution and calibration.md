# C25 Outcome attribution and calibration

**Phase 5** · The actual IP

Raw return is not learning. Attribute each closed decision to market beta, sector move,
factor exposure, earnings surprise, valuation change, timing, execution cost, thesis
error, risk-rule error or luck.

Produces self-knowledge: large-cap value 78% thesis accuracy, small-cap momentum 53%...
**The system learns where its edge is and isn't.**

Adaptation only via: outcome -> attribution -> hypothesis -> versioned experiment ->
validation -> paper -> risk committee -> human-approved promotion. Rollback supported.
Never a silent prompt, model, score or rule change.
