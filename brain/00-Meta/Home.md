# Financial-Brain

> An AI-native financial research system for Indian markets, in which the AI is the
> analyst rather than the interface.

**Status (2026-09-20):** Phases 0 and 1 complete, Phase 2 largely built and running
daily. **386 tests pass.** The system perceives, cites and refuses; it has not yet been
shown to decide well - see [[Current state]] and [[The unanswered question]].
